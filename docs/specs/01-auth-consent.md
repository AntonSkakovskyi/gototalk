# 01. Реєстрація, вхід, згода, видалення акаунта

Гілка: `feat/01-auth`. Передумова для всіх сценаріїв.

Вимоги (лаба 6): UR-1, UR-13, FR-1, FR-18, NFR-2, NFR-5.

Назва кожного тесту починається з ID тест-кейса, наприклад `[TC-01-03] ...`; перелік тест-кейсів у `docs/specs/test-cases.md`.

## Поведінка

- Реєстрація: email + пароль (мінімум 8 символів). Без підтвердження email.
- Вхід: email + пароль. Помилка не розкриває, чи існує email.
- Сесія: access JWT (~15 хв) у пам'яті фронтенду; refresh-токен (~30 днів) у httpOnly, Secure, SameSite=Strict cookie, у БД — лише хеш (`refresh_tokens`). Ротація при кожному оновленні; старий токен відкликається.
- Вихід: відкликає поточний refresh-токен.
- Згода: після першого входу, до будь-якого запису голосу, екран згоди з поясненням, що мовлення й транскрипти передаються сервісам розпізнавання й мовної моделі (назви провайдерів із конфігу), що аудіо не зберігається, і що дані можна видалити. Підтвердження записує `users.consent_at`. Без згоди сесію почати не можна (перевірка і на бекенді).
- Видалення акаунта: у профілі, з підтвердженням (повторне введення пароля). Видаляє користувача; решту прибирає каскад.

## API (контракти в `packages/shared`)

`POST /api/auth/register` · `POST /api/auth/login` · `POST /api/auth/refresh` · `POST /api/auth/logout` · `POST /api/me/consent` · `DELETE /api/me`

## Готово, коли

- Unit: хешування argon2, ротація refresh-токенів, відкликання. [TC-01-01]
- Інтеграційні: реєстрація → вхід → refresh → logout; повторне використання відкликаного refresh-токена повертає 401; `DELETE /api/me` видаляє рядки користувача в усіх пов'язаних таблицях. [TC-01-02]
- e2e (мобільний в'юпорт): реєстрація → екран згоди → головний екран; вихід → вхід. [TC-01-03]
- Захищені ендпоінти без токена повертають 401. [TC-01-04]
- Інтеграційний: помилка входу однакова для неіснуючого email і хибного пароля. [TC-01-05]
- Інтеграційний: користувач не бачить даних іншого користувача. [TC-01-06]
- Ручний: екран згоди називає сервіси, повідомляє, що аудіо не зберігається, і що дані можна видалити. [TC-01-07]
