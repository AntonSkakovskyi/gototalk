# Тест-кейси

Цей файл генерується з `iit/labs/lab9/src/tests.json` (скрипт `gen-tests.js`); редагувати там, не тут.

Нумерація: TC-NN-K відповідає K-му пункту розділу «Готово, коли» у docs/specs/NN-*.md (у специфікаціях біля пунктів стоять теги `[TC-NN-KK]`). Один тест-кейс може охоплювати кілька тестів: кожен тест лише починає назву з ID, наприклад `[TC-04-02] голосова відповідь: репліка, помилки, патерни`. Допустимий запис і з однією цифрою (`[TC-00-1]`), і з двома (`[TC-00-01]`). Звіт лабораторної 9 зіставляє JSON-репорти Vitest і Playwright за цим префіксом; тест без префікса у звіті не враховується.

Рівні: unit, integration, e2e – автоматичні тести; manual – ручні (проходить студент); inspection – перевірка артефакта (наявність файла, огляд коду) без окремого тесту. Тест-кейси, позначені «додатковий», дописано в кінець розділу «Готово, коли» відповідної специфікації.
